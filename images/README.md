# Image Assets - Overwatch Horse Racing

## Directory Structure

### `/current_roster/`
Contains visual assets for the 6 active racing characters:
- **Reinhardt Wilhelm** - Crusader Knight
- **Torbjörn Lindholm** - Master Engineer  
- **Angela Ziegler (Mercy)** - Guardian Angel
- **Brigitte Lindholm** - Shield Maiden
- **Orisa** - Guardian Omnic
- **Jack Morrison (Soldier: 76)** - Veteran Soldier

## Required Asset Types Per Character

### 1. Thumbnail (`*_thumb.png`)
- **Size**: 100x100px
- **Usage**: Character selection grid
- **Style**: Character portrait with name overlay
- **Opacity**: 10% for disabled, 100% for available characters

### 2. Portrait Large (`*_portrait.png`)  
- **Size**: 300x300px
- **Usage**: Character selection preview/closeup
- **Style**: High-detail character artwork
- **Format**: Clean portrait suitable for modal display

### 3. Racing Sprite (`*_sprite.png`)
- **Size**: 40x40px (pixelated)
- **Usage**: Racing animation on track
- **Style**: Downscaled pixel art of horse form
- **Animation**: Should work for movement sprites

### 4. Horse Form (`*_horse.png`)
- **Size**: 200x200px
- **Usage**: Character transformation display
- **Style**: Full horse/centaur form illustration
- **Theme**: Maintains character identity in equine form

## Asset Requirements

### Visual Style
- Consistent art style across all characters
- Overwatch color palette and aesthetic
- Horse/centaur transformations that maintain character identity
- High contrast for track visibility

### Technical Specs
- **Format**: PNG with transparency
- **Color Profile**: sRGB
- **Compression**: Optimized for web
- **Naming**: `{character_id}_{asset_type}.png`
